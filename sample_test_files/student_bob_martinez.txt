GCSE PE Paper 1 - Energy Systems

Question 1: Describe the aerobic energy system (3 marks)

The aerobic system makes energy using air. It happens in the body and helps you do exercise for a long time.

Question 2: Explain how the aerobic system is used during a marathon (4 marks)

In a marathon you run for a long time so you need the aerobic system because it gives you energy. Marathons are long races and you have to keep going so the aerobic system helps you not get tired.

Question 3: Evaluate the effectiveness of the aerobic system for different types of athletes (6 marks)

The aerobic system is good for some people and not good for others. People who run marathons need it because they run for ages. But sprinters don't really need it because they only run for a short time. So it depends what sport you do whether the aerobic system is good or not.

Question 4: Define SMART targets and give an example (4 marks)

SMART targets are goals that are smart. They help you know what you want to achieve in PE.

Example: I want to get better at football.

Question 5: Explain the difference between aerobic and anaerobic respiration (3 marks)

Aerobic uses air and anaerobic doesn't use air. One is for long exercise and one is for short exercise. They both make energy but in different ways.
